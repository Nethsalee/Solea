# Contributing to SOLEA

Thank you for considering contributing to SOLEA! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/solea.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes: `npm run build && npm run dev`
6. Commit your changes: `git commit -m "Add: your feature description"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Create a Pull Request

## Development Guidelines

### Code Style

- Follow the existing code style
- Run `npm run lint` before committing
- Use TypeScript for all new files
- Write descriptive commit messages

### Commit Message Format

```
Type: Brief description

Longer description if needed

Types: Add, Update, Fix, Remove, Refactor, Docs
```

Examples:
- `Add: User authentication feature`
- `Fix: Cart total calculation bug`
- `Update: Product card styling`

### Testing

- Test your changes across different screen sizes
- Ensure all links and buttons work correctly
- Check console for errors

### Component Guidelines

- Create reusable components when possible
- Use TypeScript interfaces for props
- Add proper PropTypes or TypeScript types
- Keep components focused and single-purpose

### Pull Request Guidelines

- Provide a clear description of what your PR does
- Link any related issues
- Include screenshots for UI changes
- Ensure all checks pass before requesting review

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Help others learn and grow

## Questions?

Feel free to open an issue for any questions or concerns.

Thank you for contributing! 🎉
