# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-01

### Added
- Initial release of SOLEA e-commerce platform
- Homepage with hero section, featured categories, and product showcases
- Product listing page with filters and sorting
- Product detail pages with image galleries and size selection
- Responsive navigation header with cart and wishlist icons
- Footer with newsletter subscription
- Men's and Women's collection pages
- Shopping cart functionality with localStorage persistence
- Wishlist feature
- Product data structure and API routes
- TypeScript type definitions
- Utility functions and constants
- Custom React hooks (useCart, useWishlist)
- SEO optimization with metadata and sitemap
- Security middleware
- Code formatting with Prettier and ESLint

### Technical
- Built with Next.js 16 (App Router)
- TypeScript for type safety
- Tailwind CSS for styling
- Image optimization with Next.js Image component
- Client-side state management with React hooks
- Responsive design for all screen sizes
